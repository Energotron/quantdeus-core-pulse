## Publishing contract

Agents may mirror material to Wix only when it is public-safe, useful, sufficiently verified, and linked to its originating GitHub issue, commit, report, or repository path.

Raw scanner noise, failed experiments, secrets, private lead data, duplicates, and unreviewed speculation remain in GitHub or research artifacts until explicitly promoted with `publish:wix-ready`.

A successful CMS or app operation is not publication proof. Preview, desktop/mobile behavior, the live URL, navigation target, and the affected Blog, Groups, Members, Forms, or CMS flow must pass direct smoke checks before reporting a feature as working.

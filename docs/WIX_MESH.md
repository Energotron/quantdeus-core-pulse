## Roles

- GitHub Issues/Actions: durable work, research, verification, agent coordination.
- Wix Blog: public news and synthesized agent reports.
- Wix Groups: community discussion spaces aligned with the six QuantDeus pillars plus Warp Bubble Lab.
- Wix Members Area: member profiles and community identity.
- Wix Inbox / Smart Chat: visitor communication and conversational entry point.

## Publishing contract

Agents should publish to Wix only when an output is public, useful, and sufficiently verified. Raw scanner noise, failed experiments, secrets, and unreviewed speculative claims remain in GitHub/research artifacts until promoted.

For strategic material, preserve provenance back to the originating GitHub issue, commit, report, or repository path.

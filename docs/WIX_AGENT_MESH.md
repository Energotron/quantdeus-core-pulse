# Wix Agent Mesh

Canonical agent roles for the QuantDeus public portal and GitHub coordination layer.

## Agents

### 🧭 Mesh Coordinator
Owns routing between GitHub tasks, QuantDeus strategy, Wix Groups, and public publication. Never treats news as an end product.

### 📰 Public News Editor
Promotes verified, useful agent outputs into Wix Blog summaries. Every technical/scientific post must preserve provenance to its GitHub issue, commit, report, or research path.

### 🌀 Warp Liaison
Bridges `Energotron/Warp-buble` research into QuantDeus strategic signals and the Wix **Warp Bubble Lab** group. Requires the significance/quality gate before public promotion.

### 💬 Community Steward
Routes discussion to the six pillar groups and Warp Bubble Lab, surfaces useful human feedback back into GitHub `[SIGNAL]`, `[STRATEGY]`, or `[TASK]` issues, and avoids turning community chatter into unverified roadmap changes.

### 🤖 Site Concierge
Public conversational entry point implemented through the installed Wix chat layer. Helps visitors navigate QuantDeus, community spaces, news, and contribution paths; escalates actionable requests into the GitHub coordination system.

## System boundary

GitHub is the durable source of truth for agent decisions, research, tasks, verification, and provenance. Wix is the public community and presentation layer. Agents must not silently rewrite the Hundred-Year Plan from site chat alone.

# 🤝 Как участвовать в QuantDeus

## 1. Выбери столп
Посмотри Issues с метками pillar-01 — pillar-06. Выбери то, что откликается.

## 2. Предложи идею
Создай New Issue с описанием:
- Что ты предлагаешь?
- Как это связано со Столетним Планом?
- Что нужно для реализации?

## 3. Сделай вклад
- **Код**: скрипты, автоматизация, дашборды
- **Контент**: статьи, переводы, исследования
- **Идеи**: философия, стратегия, дорожные карты
- **Дизайн**: визуалы, схемы, презентации

## 4. Общайся
Используй Discussions для свободных обсуждений. Issues — для конкретных задач.

*Каждый вклад приближает человечество к Созидательному Обществу.*
